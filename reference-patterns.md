# Academic Scrub — candidate cues (not a blacklist)

Use these as **search hints** while classifying function. A hit is not an automatic delete. See [`semantic-rules.md`](semantic-rules.md).

## L0 — Interaction / provenance (hints)

as requested / as instructed / based on your instructions / the user asked / according to the prompt / following the prompt / the prompt requires / the instructions above / as specified in the task / in response to the feedback / the previous version / this revision / I have revised / I was asked to / the requested structure / I will now / we will now / the following response / the answer below

CN: 按你的要求 / 根据提示词 / 按反馈修改 / 上一版 / 本次修订 / 我被要求

## L1 — Assignment / course / rubric (hints)

assignment / coursework / module / rubric / marking criteria / marking scheme / learning outcomes / as required by / to satisfy the requirement / for this assignment / course examples / course chain / project brief / team project / Learning Mall / Student ID (body)

CN: 这份作业 / 本作业 / 课程作业 / 作业要求 / 评分标准 / 对此本文 / 因此本文将 / 本文旨在完成 / 为满足要求 / 与团队项目的关系

**Keep:** methods that were taught; required AI-declaration cover; bibliographic “Handbook”.

## L2 — Document-production narration (hints)

The subsequent sections… / This section examines/will discuss… / The remaining checks follow… / The table below addresses the requirements… / A named product is given in Section… / why this structure was chosen / how this report satisfies / one paper at a time

**Keep:** Table/Fig/Eq/Section when they locate substance.

## L3 — Defensive rhetoric / disclaimer density (hints)

It should be noted/emphasised that / It is important to acknowledge / It is worth mentioning  
This should not be interpreted as / This is not intended/meant to / The authors do not claim / no claim is made / is not claimed  
This does not necessarily imply / does not establish / cannot establish / cannot independently establish  
is intentionally not / is not part of this model / is outside the scope / rather than retaining  
if this cannot… declare… / must be treated as / do not interpret / use X instead / recompute / reject / retain  
A high value alone cannot… / The simulation does not prove… / These examples do not establish…

**Keep:** one calibrated limit; scientific negation that distinguishes measurands; a single clear model-scope paragraph.

## L4 — Formulaic surface + narration artefacts (hints)

Critically / Importantly / Notably / More importantly / In particular (stacked) / Consequently / Accordingly  
In recent years / With the rapid development / 近年来…受到广泛关注  
delve, underscore, intricate, tapestry, pivotal, seamless, leverage (filler), foster, realm, showcase, groundbreaking, paramount, paves the way, sheds light  
Moreover / Furthermore / Additionally as consecutive openers  
not only X but also Y; rule-of-three padding  
prove / significantly (no number) / comprehensive understanding / multifaceted / nuanced  
em dash `—` in prose → comma / parentheses / split  
≳30-word or 3-clause stacks → split **only if** they hide filler, not if they carry a mechanism

**We-stacks:** We use / We define / We select / We change / We vary / We calculate / We choose (consecutive method sentences)

**Figure/table packaging:** intentionally not plotted / should not be interpreted as / our design / our selected one / current best / Not validated / Not claimed / Cannot establish (as annotation)

**Placeholder damage:** `\bimage\b` / `[image]` / empty equation objects / “at image mm”

## Claim-strength verbs (constraint)

calibrate / calibration / validate / validation / verify / verification / establish — only when earned  
Else: quantify / evaluate / assess / characterize / compare / isolate / investigate / estimate / convergence / mesh independence

Unbacked comparative adjective → cite Fig/Table or soften. Verb ≤ evidence. Keep: suggests, may, consistent with, appears to.

## Silent compliance

If a brief is supplied: Yes/No pillars only. Never narrate compliance in the manuscript.

## Residual / Part D recount list

does not / cannot / not claimed / not intended / outside the scope / should not be interpreted / no claim / intentionally / we use / we define / we selected / importantly / notably / critically / it should be noted

For each *retained* hit after scrub: is it scientifically necessary?

Do **not** Ctrl+F-delete `this report` / `this section` / `this study` / `requirement` / `following` / `limitation`. Re-read hits for **function**. Exclude AI cover zone and reference titles.
